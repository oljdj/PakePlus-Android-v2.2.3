# 子任务 08：综合诊断报告与处理方法输出

## 执行目标
实现 `page-report` 综合报告页，整合所有诊断结果，输出：异常项汇总、调节/集合/三级视功能诊断结论、原发/继发判断、融像储备评估、处理方法建议、配镜原则。

## 依赖
- 子任务 04（异常项列表）
- 子任务 05（调节诊断）
- 子任务 06（集合诊断，含原发/继发判断与融像储备评估）
- 子任务 07（三级视功能诊断）

## 详细 Prompt

### 1. page-report 页面布局

报告分为以下卡片区块，每个区块为独立卡片（白色背景、圆角、阴影、间距）：

#### 卡片 1：异常项汇总
- 标题："异常项汇总"
- 按模块分组列出所有异常项（复用子任务 04 的结果），仅显示异常项（level !== 'normal'），正常项省略
- 每项：检查项名称 + 实际值 + 正常范围 + 异常徽章

#### 卡片 2：调节功能诊断结论
- 标题："调节功能诊断"
- 如果有确诊的调节异常类型，显示确诊类型名称（加粗红色）+ 简要描述
- 如果没有，显示"调节功能正常"（绿色）
- 列出每种异常类型的必要条件满足数 / 充分条件满足数

#### 卡片 3：集合功能诊断结论
- 标题："集合功能诊断"
- 同上格式
- 如有确诊类型，额外显示八步分析关键步骤摘要

#### 卡片 4：三级视功能诊断结论
- 标题："三级视功能"
- Worth-4 点结果 + 立体视结果

#### 卡片 5：原发/继发判断
- 标题："原发与继发关系"
- 如果有原发/继发判断结果，显示："原发：XXX → 继发：YYY" + 判断规则说明
- 如果无，显示"无明确原发/继发关系"

#### 卡片 6：融像储备评估
- 标题："融像储备评估"
- 显示 Sheard 准则 / 1:1 准则的满足情况
- 不满足时显示建议棱镜量

#### 卡片 7：综合结论
- 标题："综合结论"
- 整合所有诊断的最终结论文字（一段完整描述）
- 自动生成，格式示例："该患者调节功能表现为调节不足（AMP显著降低、PRA偏低、BCC滞后），集合功能表现为集合不足（近高度外隐斜、NPC后退、AC/A偏低），调节不足为原发，集合不足为继发。三级视功能正常。"

#### 卡片 8：处理方法
- 标题："处理方法建议"
- 根据诊断结果自动匹配处理方法（PRD 4.4.2 节的对照表）：

| 诊断类型 | 处理方法 |
|---------|---------|
| 调节不足 | ①屈光矫正 ②视觉训练（推进训练/负镜阅读） ③正镜近附加（成人或特殊情况） |
| 调节过度 | ①屈光矫正 ②视觉训练（正镜阅读/调节放松） ③散瞳药物（严重时） |
| 调节不能持久 | ①屈光矫正 ②视觉训练（翻转拍+推进训练） ③正镜近附加（成人） |
| 调节灵敏度异常 | ①屈光矫正 ②视觉训练（翻转拍双向/远近字母表） |
| 集合不足 | ①屈光全矫 ②视觉训练（聚散球/裂隙尺/集合卡） ③棱镜（训练无效时） |
| 集合过度 | ①ADD处方 ②视觉训练 ③棱镜处方 |
| 散开不足 | ①屈光矫正（低矫） ②首选棱镜 ③视觉训练 |
| 散开过度 | ①屈光矫正（近视足矫/过矫） ②首选视觉训练 ③棱镜 |
| 基本型外隐斜 | ①屈光矫正 ②首选视觉训练 ③棱镜 |
| 基本型内隐斜 | ①屈光全矫 ②首选棱镜 ③视觉训练 |
| 融像性聚散异常 | ①屈光矫正 ②视觉训练（融像训练） |
| 假性集合不足 | ①调节功能训练（核心） ②集合训练（调节改善后） |

- 以优先级编号列表展示，每项可点击展开简要说明

#### 卡片 9：配镜原则
- 标题："配镜原则"
- 根据诊断类型匹配配镜原则（PRD 4.4.3 配镜原则表）：

| 异常类型 | 配镜原则 |
|---------|---------|
| 内隐斜/集合过度/调节超前 | 看远戴，看近可不戴 |
| 外隐斜/集合不足/调节不足 | 看远看近都戴 |
| 散开不足 | 低矫处方 |
| 散开过度 | 近视足矫甚至过矫，远视欠矫 |
| 基本型内隐斜 | 全矫处方 |
| 基本型外隐斜 | 最佳视力最高负镜度数 |
| 集合过度（儿童） | 建议渐进或双光眼镜 |

### 2. 底部操作栏
- "导出报告" 按钮（图片导出：html2canvas 截图或直接打印样式）
- "返回首页" 按钮

### 3. 导出功能
- 使用 `window.print()` 配合打印 CSS（@media print）实现基本导出
- 打印 CSS 隐藏 header/footer/bottom-bar，报告卡片全宽显示
