# 一、看眼位（水平眼位，垂直眼位）
`先解决垂直，再去解决水平
水平眼位正常值
- 远眼位 → +1~-3    看远：外转→散开
- 近眼位 →   0~-6    看近：内转→集合
> [!note] 符号
> 外斜：-，exo，BI
> 内斜：+，eso，BO
# 二、看问题眼位，初步分析异常眼问题
## 近眼位问题
1. 看远眼位正常或轻微外隐斜，看近有较大外隐斜 → 集合不足
2. 看远眼位正常或轻微内隐斜，看近有较大内隐斜 → 集合过度
## 远眼位问题
1. 看远有较大外隐斜，看近眼位正常或轻微外隐斜 → 散开过度
2. 看远有较大内隐斜，看近眼位正常或轻微内隐斜 → 散开不足
## 远近眼位问题
1. 看远和看近都有外隐斜，相差在4△以内 → 基本型外隐斜
2. 看远和看近都有内隐斜，相差在4△以内 → 基本型内隐斜
`基本型隐斜：远近性质都相同；远近都异常；相差在4△以内`

> [!NOTE] 例：
> （1）远-3，近-12 → 集合不足
> （2）远BO1，近BO10 → 集合过度
> （3）远15exo，近6exo → 散开过度
> （4）远-6，近-6 → 散开过度
> （5）远+3，近+12 → 集合过度
> （6）远-10，近-13 → 基本型外隐斜
# 三、看抵抗力（正负融像储备能力），眼位不够，融像来凑

> [!NOTE] Title
> 眼位检查之后，发现有一定量的内隐斜或外隐斜，但是在看近或者看远，并没有明显的不适症状。说明虽然眼位存在问题，但是抵抗力是够的，眼睛正负融像储备能力是够的。即眼睛内聚和散开的力量范围广。
## 外隐斜找BO模糊值
1. 看远外隐斜，找远BO模糊值
2. 看近外隐斜，找近BO模糊值
3. 远近都是外隐斜，找远和近的BO模糊值
正负融像储备能力依照S法则，BO模糊值是否≥2倍外隐斜量
## 内隐斜找BI恢复值
1. 看远内隐斜，找远BI恢复值
2. 看近内隐斜，找近BI恢复值
3. 远近都是内隐斜，找远和近的BI恢复值
正负融像储备能力依照1:1法则，BI恢复值是否≥内隐斜量
> [!NOTE] Title
> 储备不够的情况下，在看近或者看远，可能会出现视疲劳，甚至说复视。



外隐斜
	远眼位 → 散开过度
	近眼位 → 集合不足
	远近眼位 → 基本型外隐斜
`1. S法则：外隐斜 → 正融像BO → 模糊值≥外隐斜量2倍
`2. 远看远BO，近看近BO，远近看远近BO
内隐斜
	远眼位 → 散开不足
	近眼位 → 集合过度
	远近眼位 → 基本型内隐斜
`1. 1:1法则：内隐斜 → 负融像BI → 模糊值≥内隐斜量
`2. 远看远BI，近看近BI，远近看远近BI
# 四、看AC/A值
> [!NOTE] Title
> A：调节，C：集合，AC：调节性集合，AC/A：调节性集合与调节的比值
> 正常值：梯度法3~5△/D，计算法 5~7△/D
## 高AC/A
1. 近眼位异常→集台过度
2. 远眼位异常→散开过度
## 低AC/A
1. 近眼位异常→集台不足
2. 远眼位异常→散开不足
## 正常AC/A
1. 远近眼位都在正常范围值内
2. AC/A正常，看远和看近都有外隐斜，相差在4△以内→基本型外隐斜
3. AC/A正常，看远和看近都有内隐斜，相差在4△以内→基本型内隐斜
# 五、看眼位与调节的关系（眼位是否影响调节）
集合不足可能导致调节过度/集合过度可能导致调节不足
# 六、看原发还是继发
1. 主因调节不足，并发集合不足
2. 主因调节过度，并发集合过度
3. 主因集合不足，并发调节过度
4. 主因集合过度，并发调节不足
`相同找调节，不同找集合

> [!NOTE] 例子
> ①
> PRA：-1.00D，BCC： +1.00D，Flipper单眼，“-”镜困难
远 : -1 ，近：-10，AC/A：2
**调节不足→集合不足**
②
PRA：-1.25D，BCC：+1.25D，Flipper单眼，“-”镜困难
远：-1，近：+12，AC/A：8
**集合过度→调节不足**

# 七、看调节是否影响屈光度
1. 调节不足不影响
2. 调节过度→雾视，眼贴/眼罩，反转拍，散瞳
# 八、方案制定与处理
1. 配镜：
- 外隐斜近视足娇，远视欠矫
- 内隐斜远视足矫，近视你骄
1. 处理：
①屈兴娇正 ②视觉训练 ③缓解棱镜处方 ④附加球镜
