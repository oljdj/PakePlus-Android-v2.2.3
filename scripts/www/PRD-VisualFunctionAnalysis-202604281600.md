## 2. 背景与目标

### 2.1 背景

视功能检查是眼视光临床诊断的核心环节，涵盖调节功能、集合（聚散）功能和三级视功能三大模块。目前视功能分析存在以下痛点：

1. **判断标准不统一**：不同医师对正常值范围、诊断准则（Sheard/1:1/Percival）的掌握程度不一，易出现漏诊或误诊
2. **分析流程碎片化**：调节-集合-三级视功能需要系统联动分析（如集合不足可继发调节过度），手工分析易遗漏关联
3. **必要条件与充分条件混淆**：临床上常见将支持性证据当作确诊依据，导致过度诊断
4. **训练方案选择缺乏依据**：不同异常类型对应差异化的训练方案，人工匹配容易出错

### 2.2 目标

构建一款面向眼视光专业人员的视功能分析工具 App，实现：

- **输入检查数据后自动识别异常项**，标注偏离正常值的方向与程度
- **系统化诊断推理**，明确区分必要条件（确诊必须满足）与充分不必要条件（支持性证据）
- **综合诊断**，判断调节异常类型、集合异常类型、原发/继发关系
- **自动输出处理方法与分阶段视觉训练方案**

## 4. 功能需求

### 4.1 数据输入模块

#### 4.1.1 基础信息输入

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 年龄 | 数字 | 是 | 用于计算年龄相关正常值（如调节幅度期望值） |
| 瞳距（PD） | 数字(cm) | 是 | 用于计算法 AC/A 计算 |
| 检查距离 | 数字(m) | 否 | 近眼位测量距离，默认 0.4m |

#### 4.1.2 调节功能检查输入

| PRA（正相对调节） | 数字 | 是 | ≥2.50 | D | <降低：调节不足 |
| BCC（调节反应） | 数字 | 是 | +0.25 ~ +0.75 | D | <超前/>滞后 |
| 右眼 AMP（调节幅度） | 数字 | 是 | 15-0.25×年龄 | D | 低于期望值2D以上为调节不足 |
| 左眼 AMP（调节幅度） | 数字 | 是 | 15-0.25×年龄 | D | 同上 |
| 右眼调节灵敏度 | 数字 | 是 | ≥12 | cpm | 单眼正常值 |
| 左眼调节灵敏度 | 数字 | 是 | ≥12 | cpm | 单眼正常值 |
| 双眼调节灵敏度 | 数字 | 是 | ≥8 | cpm | 双眼正常值 |
| 右眼翻转拍通过困难类型 | 单选 | 是 | — | — | 选项：无/负片困难/正片困难/双向困难 |
| 左眼翻转拍通过困难类型 | 单选 | 是 | — | — | 选项：无/负片困难/正片困难/双向困难 |
| 双眼翻转拍通过困难类型 | 单选 | 是 | — | — | 选项：无/负片困难/正片困难/双向困难 |

> **AMP 期望值自动计算**：根据 Hofstetter 公式 `最小调节幅度 = 15 - 0.25 × 年龄`，系统自动计算并在界面上显示期望值。

#### 4.1.3 集合功能检查输入

| 字段 | 类型 | 必填 | 正常值参考 | 单位 | 说明 |
|------|------|------|-----------|------|------|
| 远距离眼位 | 数字 | 是 | +1 ~ -3 | △ | 正值=内隐斜(eso)，负值=外隐斜(exo) |
| 近距离眼位 | 数字 | 是 | 0 ~ -6 | △ | 同上 |
| AC/A 测试方法 | 单选 | 是 | — | — | 选项：计算法/梯度法 |
| AC/A 值 | 数字 | 是 | 计算法5~7，梯度法3~5 | △/D | 根据选择的方法判定正常范围 |
| AD/A 值 | 数字 | 否 | — | △/D | 辅助参考 |
| NPC（集合近点） | 数字 | 是 | 5 ~ 7 | cm | <5集合过度；>10集合不足 |
| 远距离融像范围 BI | 文本 | 是 | X/4~10/2~6 | △ | 格式：模糊/破裂/恢复 |
| 远距离融像范围 BO | 文本 | 是 | 5~13/11~27/6~14 | △ | 格式：模糊/破裂/恢复 |
| 近距离融像范围 BI | 文本 | 是 | 9~17/17~25/8~18 | △ | 格式：模糊/破裂/恢复 |
| 近距离融像范围 BO | 文本 | 是 | 12~22/15~27/4~18 | △ | 格式：模糊/破裂/恢复 |

> **AC/A 辅助计算**：选择计算法时，系统根据公式 `AC/A = PD + M × (近眼位 - 远眼位)` 提供计算辅助（用户可覆盖）；选择梯度法时，提供 `AC/A = (初始隐斜量 - 最终隐斜量) / 附加度数` 辅助计算。

|------|------|------|--------|------|

| 立体视 | 数字 | 是 | ≤60″ | 单位：秒（″） |

| 正常但需关注 | 如 AMP 正常但越高越好 | 蓝色 |

|--------|---------|---------|

| PRA | < -2.50D | 偏低（调节不足表现） |
| BCC | < +0.25D | 调节超前 |
| BCC | > +0.75D | 调节滞后 |
| AMP（单眼） | < (15-0.25×年龄) - 2 | 调节幅度显著降低 |
| 单眼灵敏度 | < 12 cpm | 调节灵敏度下降 |
| 双眼灵敏度 | < 8 cpm | 调节灵敏度下降 |
| 远眼位 | > +1 或 < -3 | 远眼位异常 |
| 近眼位 | > 0 或 < -6 | 近眼位异常 |

| 立体视 | > 60″ | 立体视异常 |

### 4.3 诊断推理模块（核心模块）

#### 4.3.1 调节功能异常诊断

系统按以下逻辑对四种调节异常类型逐一判定，输出每型的 **必要条件满足情况** 与 **充分不必要条件满足情况**：

##### A. 调节不足（Accommodative Insufficiency）

| 条件类别 | 条件 | 判定逻辑 |
|---------|------|---------|
| **必要条件** | AMP 显著降低 | 双眼AMP中较低者 < (15-0.25×年龄) - 2.00D |
| **充分不必要条件** | PRA 降低 | PRA < -2.50D 或偏低 |
| **充分不必要条件** | BCC 滞后 | BCC > +0.75D |
| **充分不必要条件** | 单眼翻转拍负片困难 | 任一眼翻转拍通过困难类型 = 负片困难 |
| **充分不必要条件** | 近BO模糊值偏低 | 近距离BO模糊值低于正常范围 |

**诊断规则**：必要条件满足 + 至少2项充分不必要条件满足 → 诊断调节不足

##### B. 调节过度（Accommodative Excess）

| 条件类别 | 条件 | 判定逻辑 |
|---------|------|---------|
| **必要条件** | BCC 超前 | BCC < +0.25D |
| **充分不必要条件** | AMP 正常 | 双眼AMP均 ≥ (15-0.25×年龄) |
| **充分不必要条件** | 单眼翻转拍正片困难 | 任一眼翻转拍通过困难类型 = 正片困难 |
| **充分不必要条件** | NRA 降低 | NRA < +2.00D |
| **充分不必要条件** | 内隐斜 | 近眼位 > 0 或远眼位 > +1 |

**诊断规则**：必要条件满足 + 至少1项充分不必要条件满足 → 诊断调节过度

##### C. 调节不能持久（Ill-sustained Accommodation）

| 条件类别 | 条件 | 判定逻辑 |
|---------|------|---------|
| **必要条件** | AMP 首测正常但重复测量下降 | 提示用户确认（AMP正常但翻转拍持续变差） |
| **充分不必要条件** | BCC 滞后 | BCC > +0.75D |
| **充分不必要条件** | 单眼翻转拍负片困难 | 任一眼翻转拍通过困难类型 = 负片困难 |
| **充分不必要条件** | PRA 偏低 | PRA < -2.50D |
| **充分不必要条件** | 近BO模糊值偏低 | 近距离BO模糊值低于正常范围 |

**诊断规则**：必要条件满足（需用户确认耐力特征） + 至少2项充分不必要条件 → 诊断调节不能持久

##### D. 调节灵敏度异常（Accommodative Infacility）

| 条件类别 | 条件 | 判定逻辑 |
|---------|------|---------|
| **必要条件** | 单眼灵敏度 < 12 cpm 或双眼灵敏度 < 8 cpm | 灵敏度检查值低于正常 |
| **充分不必要条件** | AMP 正常 | 双眼AMP均 ≥ (15-0.25×年龄) |
| **充分不必要条件** | BCC 正常 | BCC 在 +0.25D ~ +0.75D |
| **充分不必要条件** | NRA 与 PRA 均降低 | NRA < +2.00D 且 PRA < -2.50D |
| **充分不必要条件** | 翻转拍双向困难 | 任一眼翻转拍通过困难类型 = 双向困难 |

**诊断规则**：必要条件满足 + AMP/BCC正常 + 至少1项充分不必要条件 → 诊断调节灵敏度异常

**鉴别要点**：若仅双眼灵敏度异常而单眼正常 → 提示聚散功能问题而非单纯调节灵敏度异常

#### 4.3.2 集合功能异常诊断

##### 诊断流程（八步分析法）

系统按以下八步顺序进行系统推理：

**第一步：看眼位**

- 解析远眼位、近眼位的隐斜方向与量值
- 符号约定：外隐斜为负(exo/BI)，内隐斜为正(eso/BO)

**第二步：初步判断异常眼位类型**

| 眼位模式 | 条件 | 初步判断 |
|---------|------|---------|
| 近眼位问题 | 远正常/轻微外隐斜，近较大外隐斜 | → 集合不足 |
| 近眼位问题 | 远正常/轻微内隐斜，近较大内隐斜 | → 集合过度 |
| 远眼位问题 | 远较大外隐斜，近正常/轻微外隐斜 | → 散开过度 |
| 远眼位问题 | 远较大内隐斜，近正常/轻微内隐斜 | → 散开不足 |
| 远近均异常 | 远近均外隐斜，相差≤4△ | → 基本型外隐斜 |
| 远近均异常 | 远近均内隐斜，相差≤4△ | → 基本型内隐斜 |

**第三步：看抵抗力（正负融像储备）**

- 外隐斜：检查 BO 模糊值是否 ≥ 2倍外隐斜量（Sheard 准则）
  - 远外隐斜 → 检查远BO模糊值
  - 近外隐斜 → 检查近BO模糊值
  - 远近外隐斜 → 检查远近BO模糊值
- 内隐斜：检查 BI 恢复值是否 ≥ 内隐斜量（1:1 准则）
  - 远内隐斜 → 检查远BI恢复值
  - 近内隐斜 → 检查近BI恢复值
  - 远近内隐斜 → 检查远近BI恢复值
- 输出融像储备是否足够，不够时提示可能出现视疲劳/复视

**第四步：看 AC/A 值**

| AC/A 状态 | 远眼位异常 | 近眼位异常 | 判断 |
|-----------|-----------|-----------|------|
| 高 | → | 散开过度 | 集合过度 |
| 低 | → | 散开不足 | 集合不足 |
| 正常 | 远近均在正常范围 | 无显著聚散异常 | |
| 正常 | 远近均外隐斜，相差≤4△ | 基本型外隐斜 | |
| 正常 | 远近均内隐斜，相差≤4△ | 基本型内隐斜 | |

**第五步：看调节与集合关系**

- 集合不足 → 可能导致调节过度
- 集合过度 → 可能导致调节不足

**第六步：判断原发与继发**

| 原发 | 继发 | 判断规则 |
|------|------|---------|
| 调节不足 | 集合不足 | 调节异常明确+集合异常为继发 |
| 调节过度 | 集合过度 | 调节异常明确+集合异常为继发 |
| 集合不足 | 调节过度 | 集合异常明确+调节异常为继发 |
| 集合过度 | 调节不足 | 集合异常明确+调节异常为继发 |

> **核心规则**：相同性质找调节（如调节不足+集合不足→调节原发），不同性质找集合

**第七步：看调节是否影响屈光度**

- 调节不足 → 不影响屈光度
- 调节过度 → 需雾视/眼贴眼罩/反转拍/散瞳排除假性近视

**第八步：综合诊断与方案输出**（见 4.4 节）

##### 各集合异常类型的详细诊断条件

###### A. 集合不足（Convergence Insufficiency）

| 条件类别 | 条件 | 判定逻辑 |
|---------|------|---------|
| **必要条件** | 近距离明显外隐斜，远距离正常/轻微外隐斜 | 近眼位 < -6 且远眼位在 +1~-3 范围内或轻微外隐斜 |
| **必要条件** | NPC 后退 | NPC > 7cm |
| **充分不必要条件** | AC/A 低 | AC/A < 5（计算法）或 < 3（梯度法） |
| **充分不必要条件** | 近BO模糊值降低 | 近BO模糊值低于正常范围 |
| **充分不必要条件** | NRA 降低 | NRA < +2.00D |
| **充分不必要条件** | 双眼翻转拍正片困难 | 双眼翻转拍通过困难类型 = 正片困难 |
| **充分不必要条件** | BCC 可能超前（继发） | BCC < +0.25D |

**鉴别**：需排除假性集合不足（本质为调节不足，附加+0.75D或+1.00D后NPC明显改善）

###### B. 集合过度（Convergence Excess）

| 条件类别 | 条件 | 判定逻辑 |
|---------|------|---------|
| **必要条件** | 近距离明显内隐斜，远距离正常/轻微内隐斜 | 近眼位 > 0 且远眼位在正常范围或轻微内隐斜 |
| **必要条件** | AC/A 高 | AC/A ≥ 7（计算法） |
| **充分不必要条件** | 近BI恢复值降低 | 近BI恢复值降低 |
| **充分不必要条件** | PRA 降低 | PRA < -2.50D |
| **充分不必要条件** | 双眼翻转拍负片困难 | 双眼翻转拍通过困难类型 = 负片困难 |
| **充分不必要条件** | BCC > +0.75D | 调节滞后 |
| **充分不必要条件** | NPC 近移 | NPC < 5cm |

###### C. 散开不足（Divergence Insufficiency）

| 条件类别 | 条件 | 判定逻辑 |
|---------|------|---------|
| **必要条件** | 远距离较大内隐斜，近距离正常 | 远眼位 > +1 且近眼位在 0~-6 范围内 |
| **必要条件** | AC/A 低 | AC/A < 5（计算法） |
| **充分不必要条件** | 远BI恢复值降低 | 远BI恢复值降低 |
| **充分不必要条件** | PRA 降低 | PRA 偏低 |

###### D. 散开过度（Divergence Excess）

| 条件类别 | 条件 | 判定逻辑 |
|---------|------|---------|
| **必要条件** | 远距离较大外隐斜，近距离正常 | 远眼位 < -3 且近眼位在正常范围 |
| **必要条件** | AC/A 高 | 计算法 AC/A 高 |
| **充分不必要条件** | 远BO模糊值降低 | 远BO模糊值降低 |
| **充分不必要条件** | NRA 降低 | NRA 偏低 |
| **充分不必要条件** | 双眼翻转拍正片困难 | 双眼翻转拍通过困难类型 = 正片困难 |

**鉴别**：通过单眼遮盖30-60分钟或雾视(+3.00D)后测量，若远近眼位差异缩小 → 假性散开过度

###### E. 基本型外隐斜

### 4.4 综合诊断与方案输出模块

#### 4.4.1 综合诊断报告结构

系统输出的诊断报告包含以下层次：

1. **异常项汇总**：列出所有偏离正常值的检查项及偏离程度
2. **调节功能诊断**：调节异常类型 + 必要条件/充分不必要条件满足情况
3. **集合功能诊断**：集合异常类型 + 必要条件/充分不必要条件满足情况 + 八步分析过程
4. **原发/继发判断**：明确原发病因与继发影响
5. **三级视功能诊断**：Worth-4点与立体视结果
6. **融像储备评估**：Sheard准则/1:1准则满足情况
7. **综合结论**：整合所有诊断的最终结论

#### 4.4.2 处理方法输出

系统根据诊断结果自动匹配处理方法：

| 诊断类型 | 处理方法优先级 |
|---------|--------------|
| 调节不足 | ①屈光矫正 ②视觉训练（推进训练/负镜阅读） ③正镜近附加（成人或特殊情况） |
| 调节过度 | ①屈光矫正 ②视觉训练（正镜阅读/调节放松） ③散瞳药物（严重时） |
| 调节不能持久 | ①屈光矫正 ②视觉训练（翻转拍+推进训练） ③正镜近附加（成人） |
| 调节灵敏度异常 | ①屈光矫正 ②视觉训练（翻转拍双向/远近字母表） |
| 集合不足 | ①屈光全矫 ②视觉训练（聚散球/裂隙尺/集合卡） ③棱镜（训练无效时） |
| 集合过度 | ①ADD处方 ②视觉训练 ③棱镜处方 |
| 散开不足 | ①屈光矫正（低矫） ②首选棱镜 ③视觉训练 |
| 散开过度 | ①屈光矫正（近视足矫/过矫） ②首选视觉训练 ③棱镜 |
| 基本型外隐斜 | ①屈光矫正 ②首选视觉训练 ③棱镜 |
| 基本型内隐斜 | ①屈光全矫 ②首选棱镜 ③视觉训练 |
| 融像性聚散异常 | ①屈光矫正 ②视觉训练（融像训练） |
| 假性集合不足 | ①调节功能训练（核心） ②集合训练（调节改善后） |

#### 4.4.3 视觉训练方案输出

系统根据诊断结果输出分阶段训练方案：

##### 调节异常训练方案

| 异常类型 | 训练核心 | 第一阶段 | 第二阶段 | 训练终点 |
|---------|---------|---------|---------|---------|
| 调节不足 | 提升调节幅度 | 推进训练 + 负镜阅读 | 翻转拍 + 远近字母表 | 单眼+2.50/-6.00D通过 |
| 调节过度 | 调节放松 | 正镜阅读 + 镜片排序 | 翻转拍（侧重正镜） | 单眼≥11cpm，双眼≥8cpm |
| 调节不能持久 | 提升耐力 | 翻转拍（侧重负镜）+ 推进训练 | 镜片排序进阶 | 灵敏度达标且持久 |
| 调节灵敏度异常 | 摆动训练 | 翻转拍双向 + 远近字母表 | 镜片阅读排序 | 单眼≥12cpm，双眼≥8-10cpm |

##### 集合异常训练方案（三阶段体系）

| 阶段 | 目标 | 通用工具 |
|------|------|---------|
| 第一阶段 | 感知+幅度训练 | 聚散球 → 红绿可变矢量图 → 镜片阅读+翻转拍 |
| 第二阶段 | 跳跃性融像+灵敏度 | 裂隙尺 → 偏心环卡 → 救生圈卡 |
| 第三阶段 | 功能整合+迁移 | 棱镜翻转拍 → 线珠旋转训练 → 电脑视觉训练 |

各异常类型的三阶段具体方案：

- **集合不足**：阶段1目标增加PFV至30▲+调节训练；阶段2增加跳跃融像+NFV；阶段3聚散-调节-眼球运动整合
- **集合过度**：阶段1建立发散感知+调节训练；阶段2跳跃融像（裂隙尺12号集合+6号散开）；阶段3聚散转换训练
- **散开过度**：阶段1增加远距PFV+调节训练；阶段2改进远距PFV；阶段3远距聚散灵敏度
- **基本型外隐斜**：阶段1自主集合+PFV+调节；阶段2中距离融像；阶段3远距离PFV
- **基本型内隐斜**：阶段1增进近距NFV+调节；阶段2远距NFV；阶段3聚散灵敏度

##### 训练通用原则（系统提示）

1. 先单眼后双眼（单眼只有调节没有集合）
2. 先练差的眼后练相对好的眼
3. 紧张、放松训练以放松结束
4. 远、近训练以远处结束
5. 每次累计训练时间不超过30分钟，每日1-2次
6. 先进行幅度训练，再进行灵活度训练
7. 训练设备先用简单的再用难的

##### 配镜原则输出

| 异常类型 | 配镜原则 |
|---------|---------|
| 内隐斜/集合过度/调节超前 | 看远戴，看近可不戴 |
| 外隐斜/集合不足/调节不足 | 看远看近都戴 |
| 散开不足 | 低矫处方 |
| 散开过度 | 近视足矫甚至过矫，远视欠矫 |
| 基本型内隐斜 | 全矫处方 |
| 基本型外隐斜 | 最佳视力最高负镜度数 |
| 集合过度（儿童） | 建议渐进或双光眼镜 |

## 10. 附录

### 10.1 诊断准则参考

#### Sheard 准则
- 内容：融像储备应至少为隐斜量的2倍
- 公式：M = 2H（M为模糊点处的融像储备，H为隐斜量）
- 适用：外隐斜
- 作用：①棱镜定量 P=(2H-M)/3 ②改变球镜量 ③确定训练目标

#### 1:1 准则
- 内容：BI恢复点应 ≥ 内隐斜量
- 适用：内隐斜
- 作用：①棱镜定量 ②改变球镜量 ③确定训练目标

#### Percival 准则
- 内容：需求点应落在聚散度范围中间1/3处
- 公式：P=(G-2L)/3（G为水平两侧宽度大的一侧，L为宽度小的一侧）
- 适用：不看隐斜类型，只看正负融像范围
- 条件：BI、BO模糊点不能相差2倍以上

### 10.2 AC/A 计算公式

- **计算法**：AC/A = PD + M ×（近眼位 - 远眼位）
  - PD为远用瞳距(cm)，M为测量近眼位距离(m)
  - 外隐斜取负值，内隐斜取正值
- **梯度法**：AC/A =（初始隐斜量 - 最终隐斜量）/ 附加度数

> 临床提示：分析聚散异常类型用计算性AC/A；确定下加光时用梯度性AC/A

### 10.3 调节功能异常对照总结表

| 异常类型 | 调节幅度 | 调节反应 | 相对调节 | 调节灵活度 |

| 调节维持不良 | 追加后降低 | 追加后滞后 | PRA降低 | 灵活度下降 |
| 调节过度 | 正常 | 超前 | NRA降低 | 正镜通过困难 |
