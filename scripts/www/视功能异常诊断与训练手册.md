### 二、诊断准则

#### Sheard 准则
- **内容**：融像储备应至少为隐斜量的2倍
- **公式**：M = 2H（M为模糊点处的融像储备，H为隐斜量）
- **适用**：外隐斜、内隐斜
- **作用**：①为棱镜定量：P=2H-M/3；②改变球镜量满足准则；③确定视觉训练目标

#### 1:1 准则
- **内容**：BI恢复点应≥内隐斜量
- **适用**：内隐斜
- **作用**：①为棱镜定量；②改变球镜量满足1:1准则；③确定视觉训练目标

#### Percival 准则
- **内容**：需求点或正位点应落在聚散度范围中间1/3处
- **公式**：P=(G-2L)/3，G为水平两侧宽度大的一侧，L为宽度小的一侧
- **适用**：不看隐斜类型，只看正负融像范围
- **条件**：BI、BO模糊点不能相差2倍以上
- **作用**：①为棱镜定量；②改变球镜量；③确定视觉训练目标

### 三、AC/A 计算

#### 计算法
- **公式**：AC/A = PD + M ×（近眼位 - 远眼位）
- PD为远用瞳距（cm），M为测量近眼位距离（m）
- 外隐斜取负值，内隐斜取正值

#### 梯度法
- **公式**：AC/A =（初始隐斜量 - 最终隐斜量）/ 附加度数
- 例：近眼位6BI，加+1.00D后测得8BI，则AC/A = (-6-(-8))/1 = 2

> **临床提示**：分析聚散异常类型用计算性AC/A；确定下加光时用梯度性AC/A。

## 第二部分：调节功能异常

### 一、调节不足（Accommodative Insufficiency）

#### 确诊条件
| 指标 | 表现 |
|------|------|
| 调节幅度（AMP） | 降低，比年龄相关最小幅度低2D以上 |
| 调节反应（BCC） | 调节滞后（>+0.75D） |
| 单眼调节灵敏度 | 下降，-2.00D镜片通过困难 |
| PRA | 降低 |
| 近处BO模糊值 | 可能降低 |

**诊断标准**：至少符合4项可诊断调节不足

#### 症状
- 视疲劳，长时间工作后感觉疲劳欲睡
- 视远、视近均模糊，尤以近物明显，注意力无法集中
- 头痛、牵拉感，眼肌紧张，阅读字体有移动感
- 眼干、畏光、流泪
- 不能长时间视近物，希望避免近距离工作
- 可能伴头痛、颈部僵硬、全身乏力

#### 处理方式
1. **屈光矫正**：即使很低度数的远视、散光和屈光参差也应矫正
2. **视觉训练**：调节紧张训练、推进训练
3. **近距离附加**：正镜附加解决症状
4. **成人**前两项失败选择第三项；**青少年不建议近附加**
5. 面临中考、高考的特殊人群，可建议配戴渐进，但中考完后换单光+视觉训练

#### 视觉训练方案
**工具类**：
- 推进训练
- 负镜镜片阅读
- 镜片排序
- 单眼基础训练镜片

**仪器类**：
- 直线机（可代替推进训练）
- 睫状肌训练仪（可代替推进训练）

**训练要点**：
- 镜片阅读先训练负镜片
- 从低度数开始，可根据NRA/PRA选择起始镜片
- 镜片间隔0.50D或1.00D
- 一次训练使用4个镜片（3负1正），训练时间约15分钟
- 训练终点：在+2.50～最小调节幅度的一半范围内全部通过

### 二、调节过度（Accommodative Excess）

#### 确诊条件
| 指标 | 表现 |
|------|------|
| 调节幅度（AMP） | 正常 |
| 调节反应（BCC） | 调节超前（<+0.25D） |
| 单眼调节灵敏度 | 下降，+2.00D镜片通过困难 |
| NRA | 降低 |
| 眼位 | 内隐斜 |

#### 症状
- 视物模糊、视力不稳定
- 稍作近距离阅读和工作后即感眼胀、头疼
- 畏光、对光敏感
- 从视近转为视远时聚焦困难
- 容易导致看近眼睛酸痛、视物重影
- 产生假性近视或近视快速增长

#### 处理方式
1. **屈光矫正**：即使很低度数的远视、散光和屈光参差
2. **视觉训练**：调节放松训练
3. **药物治疗**：散瞳—每晚滴两次，睡前半小时滴，建议0.01%阿托品
4. **青少年渐进**：近垂直眼位存在不配渐进；内隐斜或外隐斜<6棱镜度可配

#### 视觉训练方案
**工具类**：
- 眼罩/眼贴
- 正镜镜片阅读
- 镜片排序
- 疏通眼睛周边穴位

**仪器类**：
- 热灸明目仪（可代替蒸汽眼罩）
- 远像雾视屏（可代替正镜阅读）

**训练要点**：
- 镜片阅读先训练正镜片
- 训练重点为调节放松

---

### 三、调节不能持久（Ill-sustained Accommodation）

#### 确诊条件
| 指标 | 表现 |
|------|------|
| AMP | 正常（越测越低） |
| BCC | 调节滞后 |
| 单眼Flipper | 偏低，负片通过困难 |
| PRA | 偏低 |
| 近距离BO模糊值 | 偏低（正融像） |

#### 症状
- 视疲劳，长时间工作后感觉疲劳欲睡
- 视远、视近均模糊，尤以近物明显，注意力无法集中
- 头痛、牵拉感，眼肌紧张，阅读字体有移动感
- 眼干、畏光、流泪
- 头痛、颈痛僵硬、全身乏力
- 不能长时间视近物，希望避免近距离工作

> **关键特征**：调节幅度初测正常，但重复检测时逐渐降低；调节灵敏度初期可正常，30秒后速度下降

#### 处理方式
1. **屈光矫正**：即使很低度数的远视、散光和屈光参差
2. **视觉训练**：调节紧张训练、推进训练
3. **近距离附加**：正镜附加解决症状
4. 成人前两项失败选择第三项；青少年不建议近附加

---

### 四、调节灵敏度异常（Accommodative Infacility）

#### 确诊条件
| 指标 | 表现 |
|------|------|
| 调节幅度（AMP） | 正常 |
| 调节反应（BCC） | 正常 |
| 单眼调节灵敏度 | 下降，+/-2.00D镜片通过困难 |
| NRA、PRA | 均降低 |
| 双眼调节灵敏度 | 下降 |

#### 症状
- 视物模糊：特别是从视近到视远或从视远到视近时明显
- 稍作近距离阅读和工作后即感眼胀、头痛
- 阅读困难、疲劳、嗜睡
- 阅读注意力下降
- 眼眶周围有牵拉感
- 所阅读字体移动
- 希望尽可能避免近距离工作
- 对光敏感，远近聚焦转换困难，理解力下降

#### 处理方式
1. **屈光矫正**
2. **视觉训练**：远近字母表，反转拍

#### 视觉训练方案
**工具类**：
- 远近字母表（Hart表）
- 翻转拍

**仪器类**：
- 全自动翻转拍（可代替翻转拍）
- 睫状肌训练仪（可代替远近字母表）

**训练要点**：
- 单眼双面镜正负片通过均困难时，镜片阅读先训练正镜片
- 训练终点：单眼+2.50/-6.00D灵敏度达20cpm/分；双眼±2.00D达15cpm/分

---

### 调节功能异常对照总结表

| 异常类型 | 调节幅度 | 调节反应 | 相对调节 | 调节灵活度 |
|---------|---------|---------|---------|-----------|
| **调节不足** | 降低 | 滞后 | PRA降低 | 负镜通过困难 |
| **调节灵活度不良** | 正常 | 正常 | PRA、NRA均降低 | 灵活度下降 |
| **调节维持不良** | 追加后降低 | 追加后滞后 | PRA降低 | 灵活度下降 |
| **调节过度** | 正常 | 超前 | NRA降低 | 正镜通过困难 |

## 第三部分：集合（聚散）功能异常

### 集合功能异常分类概览

| 分类          | 远距离眼位 | 近距离眼位     | AC/A | 调节特征       |
| ----------- | ----- | --------- | ---- | ---------- |
| **集合不足**    | 正常    | 高度外隐斜     | 低    | 正常         |
| **集合过度**    | 正常    | 高度内隐斜     | 高    | PRA降低      |
| **散开不足**    | 内隐斜   | 正常        | 低    | -          |
| **散开过度**    | 外隐斜   | 正常        | 高    | -          |
| **基本型外隐斜**  | 外隐斜   | 外隐斜（远近相近） | 正常   | NRA降低      |
| **基本型内隐斜**  | 内隐斜   | 内隐斜（远近相近） | 正常   | PRA降低      |
| **融像性聚散异常** | 正常    | 正常        | 正常   | NRA/PRA均降低 |
| **假性集合不足**  | 正常    | 高度外隐斜     | 低    | 调节滞后明显     |

---

### 一、集合不足（Convergence Insufficiency）

#### 确诊条件
1. 看远眼位几乎正常（无症状），看近外斜量较大
2. 集合近点（NPC）变远 >5cm
3. 计算性AC/A <5
4. 近BO模糊值降低，近正融像储备减弱
5. NRA减弱
6. Flipper双眼正片通过困难
7. BCC结果可能超前（继发性调节过度）

**诊断要点**：视近外隐斜大于视远外隐斜；AC/A偏低；NPC后退；PFV低

#### 症状
- 近距离阅读需求与实际用眼能力之间不协调
- 近有重影、复视感、模糊、聚焦困难、字体发生流动、跳动
- 眼部有牵拉、紧张感、眼球酸胀、眼周围疼
- 无法集中注意力、希望尽量避免近距离阅读
- 短时间阅读出现眼疲劳、头疼、复视、聚焦困难

#### 处理方式
1. **屈光全矫**
2. **视觉训练**：裂隙尺、集合卡、聚散球等（不接受视觉训练选择棱镜）

#### 视觉训练方案

**第一阶段**：
- **目的**：完成5cm到6m的距离自主集合和发散；增加正融像性聚散功能至30▲；增加调节幅度与调节灵敏度
- **工具**：聚散球（线珠训练→无珠训练→三点卡）→ 红绿可变矢量图 → 镜片阅读+翻转拍
- **训练终点**：配合20/30卡片，镜片阅读通过+2.00/-6.00D，可变矢量图达到30▲

**第二阶段**：
- **目的**：增加跳跃性融像聚散力，训练融合速度和正确率；增加负融像性融像功能
- **工具**：裂隙尺 → 偏心环卡 → 救生圈卡/运动注视卡
- **训练终点**：单眼灵敏度练至+2.00/-6.00D（20/30卡片，20cpm）；双眼±2.00D，15cpm

**第三阶段**：
- **目的**：训练在集合需求和发散需求之间转换，将聚散运动与扫视、转动运动结合
- **工具**：棱镜翻转拍 → 线珠旋转运动 → 电脑视觉训练
- **训练终点**：翻转拍配合聚散设备快速通过，自由空间融像结合旋转训练顺利通过

### 二、集合过度（Convergence Excess）

#### 确诊条件
1. 看远眼位几乎正常（无症状），看近内斜量较大
2. 近BI恢复值降低，近负融像储备减弱
3. 近聚散灵敏度减弱，使用BI棱镜可能出现复视
4. PRA减弱
5. Flipper双眼负片通过困难
6. BCC >+0.75D
7. 集合近点（NPC）近移
8. 计算性AC/A >7

**诊断要点**：通常伴随远视；视近内隐斜高于视远眼位；高AC/A值（>7:1）；NFV低

#### 症状
- 复视
- 眼肌紧张疲劳感、牵拉感
- 聚焦过度感觉、视物远近均可出现模糊
- 希望尽可能避免近距离工作
- 阅读时喜欢将书本放得很近
- 喜欢闭眼
- 短时间阅读出现眼疲劳、头疼、复视、注意力不集中、困倦

#### 处理方式
1. **ADD处方**，定期复查
2. **视觉训练**
3. **棱镜处方**

> 对于集合过度、内斜的儿童，建议渐进或双光眼镜，Add给的量参考近附加计算

#### 视觉训练方案

**第一阶段**：
- **目的**：教会患者感受发散并拥有自主发散能力；增加调节幅度与调节灵敏度
- **工具**：聚散球（线珠训练→无珠训练→三点卡）→ 红绿可变矢量图 → 镜片阅读+翻转拍
- **训练终点**：调节灵敏度达到12cpm，可变矢量图散开达到15▲

**第二阶段**：
- **目的**：强调跳跃性正负融像能力
- **工具**：裂隙尺+偏心环卡 → 救生圈卡/软件训练
- **训练终点**：裂隙尺12号集合卡片与6号散开卡片通过，自由空间卡通过

**第三阶段**：
- **目的**：让患者能自主地在集合和发散需求之间转换
- **工具**：红绿翻转拍+矢量图 → 卡片旋转训练
- **训练终点**：翻转拍配合聚散设备快速通过，自由空间融像结合旋转训练顺利通过

### 三、散开不足（Divergence Insufficiency）

#### 确诊条件
1. 看近几乎正常（无症状），看远时有较大内隐斜
2. 远BI恢复值降低，远负融像性储备降低
3. 远聚散灵敏度减弱，使用BI棱镜时可能出现复视
4. Flipper双眼降低，负片通过困难
5. PRA减弱
6. 计算性AC/A <5
#### 症状
- 看远重影、模糊、头痛
- 驾驶障碍

#### 处理方式
1. **屈光矫正**：低矫处方
2. **首选棱镜处方**
3. **其次视觉训练**（效果不好）

---

### 四、散开过度（Divergence Excess）

#### 确诊条件
1. 看远有较大外隐斜，看近几乎正常（无症状）
2. 远BO模糊值降低，远正融像性储备减弱
3. 远聚散灵敏度减弱，使用BO棱镜时可能出现复视
4. Flipper双眼正片通过困难
5. NRA减弱
6. 计算性AC/A高，梯度性AC/A可正常

#### 症状
- 复视
- 广场恐惧症
- 不喜欢参加群体活动

#### 处理方式
1. **屈光矫正**：近视足矫甚至过矫，远视欠矫
2. **首选视觉训练**
3. **其次棱镜处方**

#### 视觉训练方案

**第一阶段**：
- **目的**：增加远距正融像性聚散功能；增加调节幅度与调节灵敏度
- **工具**：聚散球 → 红绿可变矢量图 → 镜片阅读+翻转拍

**第二阶段**：
- **目的**：改进远距离正融像性聚散能力
- **工具**：裂隙尺 → 偏心环卡 → 救生圈卡

**第三阶段**：
- **目的**：训练远距聚散灵敏度和调节灵敏度
- **工具**：棱镜翻转拍 → 线珠旋转训练 → 电脑视觉训练
- **训练终点**：跳跃融像实现10次25▲BO和15▲BI/分钟，顺利通过负融像训练

---

### 五、基本型外隐斜（Basic Exophoria）

#### 确诊条件
1. 视远和视近均有外隐斜，二者基本相同（相差不大）
2. 计算性AC/A值正常
3. 视远和视近的正融像聚散低
4. Flipper双眼正片通过困难
5. NRA偏低
6. NPC可能后退

#### 症状
- 近距离工作视疲劳、头疼、视物模糊、复视
- 嗜睡、注意力不集中、理解能力下降
- 近距离或远距离工作学习出现上述症状

#### 处理方式
1. **屈光矫正**：最佳视力最高负镜度数
2. **首选视觉训练**
3. **棱镜处方**（不接受训练或效果不好）

#### 视觉训练方案

**第一阶段**：
- **目的**：建立自主集合能力；增加正融像性聚散功能；增加调节幅度与灵敏度
- **工具**：聚散球 → 红绿可变矢量图 → 镜片阅读+翻转拍

**第二阶段**：
- **目的**：改进中距离融像性聚散能力
- **工具**：裂隙尺 → 偏心环卡 → 救生圈卡

**第三阶段**：
- **目的**：改进远距离正融像性聚散能力
- **工具**：棱镜翻转拍 → 线珠旋转训练
- **训练终点**：翻转拍配合聚散设备快速通过，自由空间融像结合旋转训练顺利通过

---

### 六、基本型内隐斜（Basic Esophoria）

#### 确诊条件
1. 视远和视近均有内隐斜，二者基本相同
2. 计算性AC/A值正常
3. 视远和视近的负融像聚散低
4. Flipper双眼负片通过困难
5. PRA偏低
6. 集合近点（NPC）可能变近

#### 症状
- 远距离或近距离工作学习出现视物模糊、复视
- 嗜睡、注意力难以集中
- 眼疲劳、头疼

#### 处理方式
1. **屈光矫正**：全矫处方
2. **首选棱镜处方**（选择较低度数作为棱镜处方）
3. **视觉训练**（效果一般）

#### 视觉训练方案

**第一阶段**：
- **目的**：增进视近负融像性聚散能力
- **工具**：聚散球 → 红绿可变矢量图（BI方向）→ 镜片阅读+翻转拍

**第二阶段**：
- **目的**：增加远距负融像性聚散功能
- **工具**：裂隙尺 → 偏心环卡

**第三阶段**：
- **目的**：训练聚散灵敏度和调节灵敏度
- **工具**：棱镜翻转拍 → 线珠旋转训练

---

### 七、融像性聚散功能异常（Fusional Vergence Dysfunction）

#### 确诊条件
1. 无显著的隐斜
2. 正负融像性储备均减弱
3. 聚散灵敏度BI、BO均减弱
4. 双眼调节灵敏度，+/-2.00D镜片均感困难
5. NRA/PRA均减弱
6. 单眼调节灵敏度可正常
7. 正常AC/A

#### 症状
- 常见于学龄青少年、成年人、屈光不正长期未矫正者
- 视远或视近时视物模糊
- 近距离工作后有不舒适感
- 症状随时间加重，晚上更明显
- 长时间近距离工作后注意力无法集中
- 希望避免长时间近距离工作
- 初步双眼视检查不能解释与视觉有关的症状
- 晚上或近距离工作后眼上方疼痛

#### 处理方式
1. **屈光矫正**
2. **视觉训练**：融像训练

---

### 八、假性集合不足（Pseudo-convergence Insufficiency）

#### 确诊条件
- 眼位表现类似集合不足（近高度外隐斜）
- 但根本原因是调节不足导致调节性集合不足
- 调节滞后明显
- AC/A低

**与集合不足的鉴别**：假性集合不足的本质是调节问题，训练调节功能后集合问题会改善

#### 处理方式
- 首先进行调节功能训练
- 调节改善后，集合问题通常随之改善

---

## 第四部分：调节训练方法详解

### 训练总原则
1. **先单眼后双眼**（单眼只有调节没有集合）
2. **先练差的眼后练相对好的眼**
3. **紧张、放松训练以放松结束**
4. **远、近训练以远处结束**
5. 所有项目每次累计训练时间不超过半小时，每日训练1-2次

### 一、镜片阅读

**适应证**：调节不足、调节过度、调节灵敏度异常

**设备**：试镜片（+2.50～-6.00D）、视力卡、眼罩/遮盖片

**方法**：
1. 遮盖单眼，视力卡放置在40cm处
2. 通过镜片将40个视标全部看完，该镜片训练结束
3. 一次训练使用4个镜片（正/负按需分配），训练时间约15分钟
4. 从低度数开始，镜片间隔0.50D或1.00D

**训练顺序**：
- 调节不足：先训练负镜片（3负1正）
- 调节过度：先训练正镜片（3正1负）
- 调节灵敏度异常：先训练正镜片

**训练终点**：在+2.50～最小调节幅度的一半范围内全部通过

### 二、镜片排序

**适应证**：调节功能异常

**方法**：
1. 在镜片阅读基础上进行
2. 先选择两个幅度大的镜片进行排序
3. 逐渐增加镜片数量、减小幅度
4. 选择4～6个镜片排序，间隔1.50D或2.00D

### 三、推进训练

**适应证**：调节不足、集合不足

**方法**：
1. 遮盖左眼，将视标置于40cm处
2. 看清楚后逐渐移近直至模糊
3. 努力看清楚，能看清再移近
4. 不能看清则回到40cm处
5. 重复多次
6. 双眼训练同理，但需注意是否出现抑制

**注意事项**：训练1分钟、休息30秒为一个循环；确保训练时间在患者能力范围内

### 四、Hart表训练（远近字母表）

**适应证**：调节灵活度下降或不足

**方法**：
1. 远视标卡放在3m以上墙上
2. 遮盖一眼，近视标卡置于一臂远
3. 看清近视标第一排→慢慢移近→模糊后迅速看远视标
4. 以最快速度看清远视标
5. 交替阅读远/近视标，保持清晰

**训练终点**：每分钟可将远近视标卡全部字母阅读完成

### 五、翻转拍训练

**单眼翻转拍**：
- 适应证：单眼调节灵活度下降
- 设备：±2.00D翻转拍、20/30近距视力表
- 终点：+2.50/-6.00D翻转拍保持清晰，达20cpm

**双眼翻转拍**：
- 适应证：调节灵活度下降和聚散功能异常
- 终点：±2.00D翻转拍保持清晰，达15cpm
- 注意：双眼调节灵活度之差在2cpm内再做双眼训练

### 六、调节训练三阶段方案

**第一阶段**：
- 工具：镜片阅读、镜片排序、远近字母表、聚散球集合训练、集合卡、可变矢量图集合训练
- 终点：镜片阅读通过+2.00/-6.00D，可变矢量图达到30▲

**第二阶段**：
- 工具：单/双眼翻转拍，可变矢量图散开训练，裂隙尺散开训练
- 终点：单眼+2.00/-6.00D灵敏度20cpm；双眼±2.00D灵敏度15cpm

**第三阶段**：
- 工具：翻转拍+裂隙尺，棱镜翻转拍，线珠旋转训练
- 终点：翻转拍配合聚散设备快速通过，自由空间融像结合旋转训练顺利通过

## 第五部分：集合（聚散）训练方法详解

### 一、聚散球（Brock线）训练

**适应证**：集合不足、集合近点在一臂距离内的患者

**方法**：
1. 固定聚散球一端，另一端与视线平行
2. 注视红球，感受黄球和绿球发散性复视
3. 注视黄球，感受红球和绿球的复视
4. 注视绿球，感受黄球和红球的倒V型复视

**改变球的位置**：也可用于集合过度或内隐斜患者

### 二、集合卡训练

**适应证**：集合不足、融像范围较窄患者

### 三、红绿可变矢量图训练

**适应证**：各种聚散功能异常

**集合训练**：增加BO（集合方向）需求
**散开训练**：增加BI（散开方向）需求

### 四、裂隙尺训练

**适应证**：聚散范围不足、集合不足、散开不足

**集合训练**：完成12张卡片（约30▲BO）
**散开训练**：完成7张卡片（约15▲BI）

### 五、偏心圆卡训练

**适应证**：集合不足或融像范围较窄患者

### 六、救生圈卡训练

**适应证**：聚散灵敏度训练

### 七、实体镜训练

**适应证**：融合功能异常（内隐斜、外隐斜、集合不足、集合过度）

### 八、棱镜翻转拍训练

**适应证**：聚散灵敏度训练

**方法**：一面BO棱镜，一面BI棱镜，快速翻转

## 第六部分：综合训练方案

### 视觉训练一般原则
1. **首先矫正屈光不正**
2. 让顾客了解训练目的
3. **首先训练较难的方向**（如集合不足先训练集合方向再训练散开方向）
4. **先进行幅度训练，再进行灵活度训练**
5. 训练设备先用简单的再用难的
6. 最终训练目标是各项视功能都正常

### 训练设备选择顺序（以集合不足为例）
1. 聚散球、集合卡
2. 偏振立体图、红绿矢量图
3. 裂隙尺
4. 偏心圆卡片
5. 救生圈卡

### 训练时间安排
- **视功能异常训练**：每次20-30分钟，3-4项工具，每周1-2次
- **弱视训练**：每次30-60分钟，3-4项工具，每周1-2次
- **家庭训练**：每天1-2次，每次8-10分钟，1-2款产品交替训练
- **训练室训练**：每周1-2次，每次40-45分钟，3-4款产品

### 症状与异常对应关系
| 症状 | 可能异常 |
|------|---------|
| 阅读或近距离工作时眼部疲劳不适 | 调节不足、集合不足 |
| 阅读或近距离工作时头痛 | 调节过度、集合过度 |
| 阅读或近距离工作时易困乏 | 调节不足 |
| 阅读或近距离工作时注意力不集中 | 集合不足 |
| 阅读或近距离工作时出现重影 | 集合不足（少数集合过度） |
| 记不住读过的东西 | 调节灵敏度异常 |
| 阅读速度慢 | 调节灵敏度异常 |
| 眼痛、眼酸 | 调节过度、集合过度 |
| 眼球牵拉感 | 集合不足、集合过度 |
| 阅读"串行" | 集合不足、调节灵敏度不良 |
| 重复读同一行 | 调节灵敏度异常 |
| 回避阅读 | 集合不足、调节不足、调节过度 |
| 远近聚焦转换困难 | 调节灵敏度异常 |

### 镜片阅读起始顺序规则
| 异常类型 | 镜片阅读起始 |
|---------|------------|
| 调节不足 | 先训练负镜片 |
| 调节过度 | 先训练正镜片 |
| 调节灵敏度异常 | 先训练正镜片 |
| 不确定时 | 先从正镜片开始 |

## 第七部分：配镜原则与注意事项

### 不同异常的配镜原则
| 异常类型 | 配镜原则 |
|---------|---------|
| 内隐斜、集合过度、调节超前 | 看远戴，看近可不戴 |
| 外隐斜、集合不足、调节不足 | 看远看近都戴 |
| 散开不足 | 低矫处方 |
| 散开过度 | 近视足矫甚至过矫，远视欠矫 |
| 基本型内隐斜 | 全矫处方 |
| 基本型外隐斜 | 最佳视力最高负镜度数 |
| 集合过度（儿童） | 建议渐进或双光眼镜 |

### 假性近视的调节功能异常表现
1. BCC超前
2. NRA偏低
3. 单眼翻转拍正片通过困难

### 近视增长过快的调节功能异常表现
1. BCC ≥ +1.00D
2. PRA偏低
3. 单眼反转拍负片通过困难

> **重要提示**：光线越暗滞后越明显，动用调节越多滞后越明显，滞后越多近视增长越快。青少年视近要保证足够照明！
